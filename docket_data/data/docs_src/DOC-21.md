# DATA PROCESSING ADDENDUM

This Data Processing Addendum ("**DPA**") forms part of the Cloud Services Agreement dated 24 April 2025 between Stratus Cloud Pte. Ltd. ("**Processor**") and Velora Consumer Private Limited ("**Controller**").

1. **Scope.** The Processor processes personal data of the Controller's customers (names, contact details, order history) solely to host the Controller's e-commerce workloads.

2. **Location.** Production data at rest shall be stored in the Mumbai (India) region. Backups may be stored in Singapore.

3. **Applicable law.** The Processor shall assist the Controller in complying with the Digital Personal Data Protection Act, 2023 (India) and the Personal Data Protection Act 2012 (Singapore), as applicable.

4. **Breach notification.** The Processor shall notify the Controller of any personal data breach without undue delay and in any event within twenty-four (24) hours of becoming aware of it.

5. **Sub-processors.** The current list of sub-processors is available at the Processor's trust portal; the Processor shall give thirty (30) days' prior notice of any new sub-processor.

6. **Deletion.** On termination, the Processor shall delete Controller personal data within sixty (60) days, save as required by law.
